# openmasonry.github.io

The landing page of [OpenMasonry](https://github.com/openmasonry/openmasonry): one static page with no external scripts, fonts or trackers. The live numbers come from the [Observatory](https://openmasonry.github.io/openmasonry/).

The coats of arms in `arms/` are drawn from the full blazons in the canon of the main repository (field, ordinary and charge). Text under CC BY-SA 4.0, code under the MIT license, as in the main repository.
